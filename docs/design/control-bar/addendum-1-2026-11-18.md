# Skreenrek control bar: addendum 1 (2026-11-18, after PR #47 at 11f9be4)

These notes correct or extend spec.md.

1. §8 Capture exclusion, corrected. The bar's window uses `sharingType = .none`, which keeps it out of every capture. Do not add the bar to `exceptingWindows`, because that would put it back into the capture. Region captures already exclude the app. Acceptance: the bar never appears in a clip, whether the clip is a window, a region or a full-screen capture.
2. When the bar shows for agent recordings. The bar follows the recording HUD's rule.
   - If the agent passed `--no-hud`, the bar is not shown at all. "No on-screen chrome" covers the bar too.
   - If an agent records a window without a pick and the HUD is shown, the bar shows in its recording state (timer and Stop), in place of the HUD's recording state, as in spec §9. It is hidden again when the recording ends, unless the user has that window picked.
3. Timer. Under an hour it reads m:ss (0:12, 59:59). From an hour it reads h:mm:ss (1:02:03). This is the QuickTime pattern. Use monospaced digits so the bar doesn't jitter. The bar stays 300 pt wide, and the readout slot absorbs the extra width.
4. Compact bar (192 pt). Saving and the size warnings move into the tooltip and VoiceOver. Accepted.
5. Panel height cap. It is now 648 pt, which matches §10's overage. Accepted.
6. Accessibility off. The bar's Record records the window at its current size. Size is disabled, and the readout shows the current px with the not-exact triangle. The tooltip reads "Skreenrek can't resize windows without Accessibility. Recording at the current size." The panel keeps its error. Accepted.
7. Saving state. The spinner sits directly left of "Saving clip…" with a 6 pt gap, and the pair is centred together in the size and readout area. The spinner should not be pinned to the far left edge.
8. Picker size chip (from the solid panel work, PR #43 at d23266c). It has 8 pt of horizontal padding and 4 pt of vertical padding. The text is 12 pt with monospaced digits. The radius is 4 pt and the surface is the same solid surface as the panel.
